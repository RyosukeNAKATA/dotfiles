# Core Behavior Rules (00-core.md)

## 1. コミュニケーション原則
- 特別な指定がない限り、対話や解説は自然かつ正確な日本語で行うこと。
- 回答は簡潔かつ構造化（Markdown表記）して提示すること。

## 2. 思考・問題解決プロセス
- 変更や修正を行う前に、必ず関連するコードベースや設定ファイルを検索・閲覧し、現状を正確に把握すること。
- エラーが発生した場合は、推測で対症療法を行わず、エラーログやスタックトレースの根本原因を調査・特定してから対応すること。
- 不明な点や曖昧な要求がある場合は、勝手に決めつけずユーザーに明確化を求めること。
