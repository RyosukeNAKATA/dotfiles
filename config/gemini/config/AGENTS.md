# AI Coding Agent Shared Instructions (AGENTS.md)

このファイルはすべての AI コーディングエージェント（Antigravity, Gemini CLI, Claude Code, GitHub Copilot 等）で共有される共通行動指針です。

## 基本動作規則

1. **言語設定**: 特別な指示がない限り、会話・解説・思考ログの要約はすべて日本語で行ってください。
2. **ルール読み込み**: `~/.gemini/config/rules/` に配備されたすべてのルールを遵守してください。
   - `00-core.md`: コミュニケーション・基本思考プロセス
   - `10-code-style.md`: コード品質・設計原則
   - `20-git-workflow.md`: Gitコミット・運用規約
   - `30-safety.md`: 安全ガードレール・環境破壊防止
3. **正確性の追求**: コードや仕様を推測で記述せず、必ず実ファイルや設定を検索・確認した上で変更を行ってください。
4. **検証の義務**: コード修正後は、必ずビルド・テスト・ログ確認を実行して正常動作を確認してください。
